# توازنها صح — منصة اليوم العالمي للسكري (Tawazonha Diabetes Day)

مشروع ويب حديث ومستقل تم بناؤه خصيصاً لفعاليات **اليوم العالمي للسكري** ومبادرة **توازنها صح**، مع الحفاظ على الهوية البصرية للشركة (الألوان، الخطوط، الأيقونات والشعارات) ولكن باعتماد بنية تكنولوجية حديثة وموحدة كلياً (**Next.js 15 App Router + Framer Motion + Tailwind CSS + Neon PostgreSQL**).

---

## 🌟 مميزات المشروع والبوابات الثلاث

### 1. الصفحة الرئيسية (`/`)
- **حلقة التوازن الأيضي الحية (Living Balance Ring)**: أنيميشن سينمائي تفاعلي يمثل شعار اليوم العالمي للسكري والتوازن الأيضي بألوان توازنها.
- **البوابات الثلاث المتحركة (Hero Portal Cards)**: 3 كروت تفاعلية تظهر بتأثير حركي متسلسل (Staggered Animation) مع تفاعل ثلاثي الأبعاد وتوهج لوني مخصص:
  1. **المنصة التفاعلية (`/portal`)**: فتح موقع المنصة التفاعلي داخل إطار مدمج وشريط تحكم مخصص **دون تغيير الدومين الأساسي**.
  2. **تواصل معنا (`/contact`)**: نموذج حجز استشارة طبية يحفظ البيانات مباشرة في قاعدة بيانات **Neon Cloud PostgreSQL**.
  3. **من نحن (`/about`)**: قصة المبادرة، وأهداف اليوم العالمي للسكري، والركائز الطبية الأربعة، وقسم الأسئلة الشائعة التفاعلي (FAQ).
- **شريط الإحصائيات والأثر**: إحصائيات ونسب الوقاية من مضاعفات السكري بنمط الحياة المتوازن.
- **ركائز توازنها الأربعة**: الفحص الاستباقي، التغذية المتوازنة، النشاط البدني الذكي، والرعاية المتخصصة.

---

### 2. المنصة التفاعلية المدمجة (`/portal`)
- تعرض الموقع المطلوب عبر مسار مدمج **دون أن يخرج المستخدم من الرابط الأساسي**.
- **شريط تحكم متكامل**:
  - زر العودة للرئيسية (`← العودة للرئيسية`).
  - شعار توازنها المضيء.
  - زر إعادة تحميل المنصة (Reload).
  - زر ملء الشاشة (Fullscreen Toggle).
  - زر فتح في نافذة مستقلة خارجية.
  - **نافذة ضبط وتعديل الرابط المدمج**: تتيح تجربة أو تغيير أي رابط في ثوانٍ.

---

### 3. صفحة تواصل معنا (`/contact`) وقاعدة بيانات Neon
- نموذج استشارة متكامل يشمل:
  - **الاسم بالكامل** (`full_name`)
  - **رقم الجوال / الهاتف** (`mobile`)
  - **البلد / المدينة** (`city`)
  - الموافقة على شروط الرعاية الطبية والخصوصية
- **اتصال مباشر بـ Neon Database**:
  - يتم التحقق من المدخلات وإرسالها إلى مسار الباك إند المدمج `POST /api/contact`.
  - تُحفظ البيانات في جدول `contact_submissions` السحابي في Neon مع توثيق الـ IP وتوقيت الحجز بدقة.
  - إشعار نجاح فوري وتأكيد بالمعرف الفريد (UUID).

- اتصال بالإنترنت للاتصال بـ Neon PostgreSQL

NEXT_PUBLIC_PORTAL_URL=https://twaznha-website-link.vercel.app
NEXT_PUBLIC_PORTAL_TITLE=منصة توازنها التفاعلية

### 3. أوامر التشغيل
```bash

npm run dev

# أو تشغيل الخادم الإنتاجي المحسن
npm run build
npm start
```
الموقع يعمل على: `http://localhost:3000`
